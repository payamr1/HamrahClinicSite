# فونت‌ها

فونت سایت **نارنگی پرو** است؛ نسخه‌ی variable که در یک فایل همه‌ی
وزن‌های ۱۰۰ تا ۹۰۰ را دارد.

```
NarengiVF.woff2     ← تنها فایل فونتی که سایت بارگذاری می‌کند
FontLicense.txt     ← ثبت مشخصات پروانه، طبق خواسته‌ی فروشنده
```

## چرا نسخه‌ی variable

قالب سایت شش وزن می‌خواهد: ۳۰۰، ۴۰۰، ۵۰۰، ۶۰۰، ۷۰۰، ۸۰۰.

| | حجم |
|---|---|
| شش فایل جداگانه (هرکدام ~۵۳ کیلوبایت) | ~۳۲۰ کیلوبایت |
| **یک فایل variable** | **۱۸۸ کیلوبایت** |

یعنی هم سبک‌تر است، هم وزن‌های میانی را واقعاً دارد و مرورگر مجبور
نیست ضخیمشان کند (fake bold).

## چرا نسخه‌ی FaNum را نگذاشتیم

بسته یک نسخه‌ی «Farsi Numerals» هم دارد که رقم‌های لاتین را با
شکل فارسی نشان می‌دهد. استفاده نکردیم چون سایت خودش این تبدیل را
با تابع `fa()` انجام می‌دهد، و بعضی جاها عمداً رقم لاتین لازم است —
ابعاد عکس در پنل، حجم فایل، و شماره‌ی داخل `tel:`. کنترل در کد
بهتر از کنترل پنهان در فونت است.

## بسته‌ی اصلی کجاست

بیرون از این مخزن:

```
C:\share folder\_fonts-original\
```

**عمداً** اینجا نیست: این مخزن عمومی است و بسته‌ی اصلی ۵۷ فایل TTF
و OTF نصب‌شدنی دارد. سرو کردن `woff2` از سایت استفاده‌ی عادی وب
است، ولی گذاشتن فایل‌های نصب‌شدنی در یک مخزن عمومی گیت‌هاب
بازتوزیع فونت تجاری حساب می‌شود.

اگر روزی وزن‌های جداگانه یا نسخه‌ی دسکتاپ لازم شد، از همان پوشه
بردارید. `License.pdf` و `شرایط-استفاده.pdf` هم همان‌جاست.
