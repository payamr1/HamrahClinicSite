# فونت‌ها

فایل‌های فونت را در همین پوشه بگذارید. فقط `.woff2` — هر قالب
دیگری (ttf، otf، woff) دو تا چند برابر حجم دارد و هیچ مرورگری که
امروز استفاده می‌شود به آن نیاز ندارد.

## نام‌گذاری

نام فایل‌ها باید **دقیقاً** این‌ها باشد، وگرنه CSS پیدایشان نمی‌کند:

### اگر IRANSansX دارید (توصیه‌شده)

```
iransansx-variable.woff2
```

یک فایل، همه‌ی وزن‌ها. سبک‌تر از مجموع فایل‌های جداگانه است و
وزن‌های میانی (۶۰۰ و ۸۰۰) را واقعاً دارد.

### اگر IRANSans کلاسیک دارید

```
iransans-light.woff2      ← وزن ۳۰۰
iransans-regular.woff2    ← وزن ۴۰۰
iransans-medium.woff2     ← وزن ۵۰۰
iransans-bold.woff2       ← وزن ۷۰۰
iransans-black.woff2      ← وزن ۹۰۰
```

## نکته‌ی مهم درباره‌ی وزن‌ها

قالب سایت از شش وزن استفاده می‌کند: ۳۰۰، ۴۰۰، ۵۰۰، ۶۰۰، ۷۰۰، ۸۰۰.

IRANSans کلاسیک **وزن ۶۰۰ و ۸۰۰ ندارد**. اگر این نسخه را بگذارید،
مرورگر یا نزدیک‌ترین وزن را برمی‌دارد یا خودش ضخیمش می‌کند
(fake bold) که زشت درمی‌آید. در آن صورت باید وزن‌های CSS را به
آنچه واقعاً وجود دارد نگاشت کنیم — بگویید تا انجام دهم.

IRANSansX این مشکل را ندارد.

## تبدیل به woff2

اگر فقط ttf یا otf دارید:

- <https://transfonter.org> — گزینه‌ی woff2 را بزنید، بقیه را بردارید
- یا `woff2_compress` از پکیج `woff2` روی لینوکس

## پروانه

IRANSans و IRANSansX **فونت تجاری‌اند** و برای استفاده‌ی تجاری
پروانه می‌خواهند. پیش از انتشار نهایی مطمئن شوید پروانه‌ی معتبر
دارید. اگر نداشتید، Vazirmatn جایگزین رایگان (OFL) و بسیار
نزدیکی است و همین الان روی سایت است.
