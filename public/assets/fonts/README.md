# فونت‌ها

فونت سایت **نارنگی پرو** است؛ نسخه‌ی variable که در یک فایل همه‌ی
وزن‌های ۱۰۰ تا ۹۰۰ را دارد.

```
NarengiVF.woff2     ← تنها فایل فونتی که سایت بارگذاری می‌کند
FontLicense.txt     ← ثبت مشخصات پروانه، طبق خواسته‌ی فروشنده
```

## چرا نسخه‌ی variable

قالب سایت شش وزن می‌خواهد: ۳۰۰، ۴۰۰، ۵۰۰، ۶۰۰، ۷۰۰، ۸۰۰.

| | حجم |
|---|---|
| شش فایل جداگانه (هرکدام ~۵۳ کیلوبایت) | ~۳۲۰ کیلوبایت |
| **یک فایل variable** | **۱۸۸ کیلوبایت** |

یعنی هم سبک‌تر است، هم وزن‌های میانی را واقعاً دارد و مرورگر مجبور
نیست ضخیمشان کند (fake bold).

## چرا نسخه‌ی FaNum را نگذاشتیم

بسته یک نسخه‌ی «Farsi Numerals» هم دارد که رقم‌های لاتین را با
شکل فارسی نشان می‌دهد. استفاده نکردیم چون سایت خودش این تبدیل را
با تابع `fa()` انجام می‌دهد، و بعضی جاها عمداً رقم لاتین لازم است —
ابعاد عکس در پنل، حجم فایل، و شماره‌ی داخل `tel:`. کنترل در کد
بهتر از کنترل پنهان در فونت است.

## هیچ فایل فونتی در این مخزن نیست

نه `woff2`، نه `ttf`، نه `otf`. `.gitignore` هر چهار پسوند را
کنار می‌گذارد و فقط همین README و `FontLicense.txt` در مخزن
می‌مانند.

دلیل: این مخزن عمومی است. سرو کردن `woff2` از خود سایت استفاده‌ی
عادی وب است — هر بازدیدکننده‌ای ناچار آن را می‌گیرد. ولی گذاشتن
همان فایل در یک مخزن عمومی گیت‌هاب یعنی هرکسی می‌تواند برش دارد،
و این دیگر بازتوزیع فونت تجاری است.

`FontLicense.txt` عمداً می‌ماند: فروشنده می‌خواهد کنار فونت باشد،
و خودش فونت نیست.

## پس فونت روی سرور از کجا می‌آید

مستقیم آپلود شده، در `~/public_html/assets/fonts/`.

استقرار cPanel با `cp -R` انجام می‌شود و هیچ‌وقت چیزی را پاک
نمی‌کند — همان قاعده‌ای که پوشه‌ی `uploads/` با آن سالم می‌ماند.
پس فایل با هر بار Deploy سر جایش است.

**بهای این تصمیم:** اگر سرور از نو ساخته شود، فونت نمی‌آید و سایت
بی‌صدا با Tahoma بالا می‌آید. نه خطایی، نه صفحه‌ی سفیدی. برای
همین `_health.php` بودن فایل را بررسی می‌کند و نبودش را بررسی
**حیاتی** می‌شمارد، نه هشدار.

### اگر لازم شد دوباره آپلودش کنید

نسخه‌ی کاری همین‌جاست — روی دیسک هست، فقط در گیت نیست:

```
public/assets/fonts/NarengiVF.woff2
```

cPanel ▸ File Manager ▸ `public_html/assets/fonts/` ▸ Upload.
بعد `_health.php` را باز کنید؛ سطر «فایل فونت نارنگی» باید سبز
شود.

## بسته‌ی اصلی کجاست

بیرون از این مخزن:

```
C:\share folder\_fonts-original\
```

۵۷ فایل TTF و OTF نصب‌شدنی، به‌علاوه‌ی `License.pdf` و
`شرایط-استفاده.pdf`. اگر روزی وزن‌های جداگانه یا نسخه‌ی دسکتاپ
لازم شد، از همان‌جا بردارید.
